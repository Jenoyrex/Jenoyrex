# Icon and font sources

The images in `assets/icons/` and `assets/buttons/` are generated by `scripts/build-icons.mjs`
from these packages. Logos remain trademarks of their owners and are used only to identify
the technologies.

| Source | Used for | Licence |
|---|---|---|
| [simple-icons](https://github.com/simple-icons/simple-icons) | Technology logos, GitHub, Gmail | CC0-1.0 |
| [@lobehub/icons](https://github.com/lobehub/lobe-icons) | Anthropic, OpenAI | MIT |
| [Tabler Icons](https://github.com/tabler/tabler-icons) | SQL, LinkedIn | MIT |
| [Lucide](https://github.com/lucide-icons/lucide) | Section and project icons, external-link | ISC |

Alembic and fastembed have no official logos, so their tiles show the name in text.

`assets/hero.gif` is rendered by `scripts/hero/render.mjs` using the Inter and JetBrains Mono
typefaces (SIL Open Font License 1.1, via @fontsource).
